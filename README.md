# My Game

A Unity game project.

## Getting Started

1. Install [Unity Hub](https://unity.com/download) and a compatible Unity Editor version.
2. Open Unity Hub → **Add** → select this folder.
3. Once the Unity Editor creates its project files (`Assets/`, `ProjectSettings/`, etc.), commit them to this repository.

## Project Structure

- `Assets/` — game scenes, scripts, and art (created by Unity)
- `ProjectSettings/` — Unity project configuration (created by Unity)

## Contributing

1. Create a branch for your change.
2. Commit with a clear message.
3. Open a pull request describing what changed and why.
